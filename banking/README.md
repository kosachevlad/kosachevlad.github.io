# Навчальний банк · 11 клас

Український статичний тренажер інтернет-банкінгу. Без залежностей, реєстрації, аналітики та справжніх платежів.

Відкрити: https://kosachevlad.github.io/banking/

## Можливості

- Віртуальні 5 000 грн, ліміт покупки та історія операцій.
- Три рахунки з перевіркою особового рахунку, комісії й суми.
- Магазин, навчальні умови продавця, доставка/самовивіз, перевірка ліміту та балансу.
- Імітація підтвердження (навчальний код 246810), скасування без списання, захист від повтору.
- Навчальні квитанції, підтвердження замовлення, текстовий експорт і друк результату.
- Вправа з шахрайством, тест із поясненнями, оцінка до 12 балів.
- Посібник учителя на 45 хвилин у розділі «Посібник учителя».

## Локальний запуск

Потрібен Node.js. З кореня репозиторію: `node --test banking/test.cjs`.
Для перегляду достатньо відкрити `banking/index.html` або використати будь-який статичний HTTP-сервер.

## Публікація

Папка `banking/` публікується на GitHub Pages разом із наявним сайтом із гілки master. Головна сторінка не змінюється. Усі посилання на ресурси відносні.

## Дані й межі

Суми рахуються цілими копійками. Прогрес зберігається в localStorage за ключем school-bank-v1. Дані не надсилаються серверу, результати можна змінити засобами браузера; це тренажер, а не захищена система оцінювання. Паралельна робота кількох вкладок не призначена для незалежних учнів. На спільному пристрої очищуйте спробу між учнями.

Справжні карткові реквізити не запитуються. Імена продавців, адреси, рахунки, тарифи та гарантійні умови вигадані. Навчальна квитанція не є фіскальним чеком. Умови повернення спрощені для вправи та не є універсальним юридичним правилом.
