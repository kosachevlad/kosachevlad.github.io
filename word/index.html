Як надіслати файл учителю у Viber

Відкрийте чат з учителем у Viber.

  1. + Натисніть «+» біля поля повідомлення.
  2. Виберіть «Файл».
  3. У папці «Завантаження» знайдіть файл і надішліть його.

У Провіднику Windows також можна клацнути файл правою кнопкою й вибрати «Поділитися».
